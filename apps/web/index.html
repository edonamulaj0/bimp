How it works

From a drawing set to an answer you can point to.

No new process. Upload what you already have, ask what you would ask a colleague, and check the answer where it lives on the drawing.

01

Upload the set

bimp reads every sheet once: walls, rooms, doors, windows, fittings, labels in their own language, and the scale.

  • The model reads; code measures and checks
  • Scale from the sheet, cross-checked with a dimension
  • Every plan marked measured or preview
02

Ask in plain words

"How big is bedroom 2?" "How many windows does the office have?" Answers come with the rooms they came from, and every number is checked against the plan before you see it.

  • Areas, perimeters, heights, volumes
  • Counts of doors, windows and fittings
  • Net and gross floor area
03

Check it on the sheet

Click an answer and the canvas jumps to it. Overlay the source drawing, switch to the isometric model, trace an escape route, print at a true 1:x scale.

  • 2D plan, isometric dollhouse, or both side by side
  • Escape distances and checks against design standards
  • Print to scale on A4–A0

Why you can trust it

No source, no answer.

A guess you cannot check is worse than no answer. bimp says "not found in the drawings" before it makes something up.

01

Every number is traced

Each figure in an answer must appear in the plan, the question or a stated assumption, or the answer is marked unverified.

02

Measured only when it is

A plan is "measured" only when the drawing states its scale exactly and the outlines match its own line work. Everything else says preview.

03

Rules with their source

Checks cite the table they come from. Conflicts between a stated scale and a dimension are shown, not hidden.
