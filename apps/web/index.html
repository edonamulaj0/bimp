02MethodAsk · Mark up · Compare · Check

One sheet, read four ways.

The drawing stays the source of truth. bimp only adds what can be traced back to it, and says so when it can't.

Ask

Plain questions in your language. Every answer lists the rooms it came from; numbers that can't be traced to the plan are marked unverified.

Mark up

Drag a region over the plan or the model. bimp answers from the rooms, walls, openings and fittings inside it, and nothing else.

Compare

Each new issue becomes the next revision. Compare any two: rooms added, removed or resized, and the change in net and gross area.

Check

Room sizes, corridor and door widths, daylight and escape distances, each flag citing the Metric Handbook table it comes from.

From sheet to model.

  1. The sheet is read

    Line work, text and the stated scale become room outlines with exact areas.

  2. Walls rise

    Wall thicknesses from the drawing; openings cut where the doors and windows are.

  3. Heads and levels

    Ceiling height and floor level when the drawing states them, assumed and labelled when it doesn't.

  4. A model to question

    Orbit it, cut it at 1.2 m, mark a region and ask.
