Method

The model reads. The tools measure.

General AI guesses at drawings. bimp is built so that it can't: every number comes from geometry or text it can point to, and anything it isn't sure of is labelled as such.

01

No source, no answer

Each answer lists the rooms or sheet regions it came from, and clicking one shows it on the canvas. Before an answer is shown, every number in it is checked against the plan, the question and the stated assumptions. A number that cannot be traced marks the answer as unverified.

If the drawings don't contain the answer, bimp says so and lists what it looked at.

02

Measured, or preview

A plan is marked measured only when both are true: the drawing states its scale exactly (a vector sheet's 1:N, or a DXF's units), and at least 90 % of room corners match the drawing's own line work. Everything else is a preview, and says so on the canvas.

Scale is chosen in a fixed order, and each step is recorded with the plan:

  • Scale stated on the sheet, or exact DXF units
  • Scale written in the title block, confirmed by a dimension within 5 %
  • A dimension, rounded to the nearest preferred scale when the paper size is known
  • A dimension alone; then typical door width; then an assumed width, always flagged

When a stated scale and a dimension disagree, bimp reports the conflict instead of choosing silently.

03

Code does the arithmetic

Areas, perimeters, volumes, counts and escape distances are computed from the plan's geometry. Dimension text is parsed by code following drawing convention: millimetres without decimals, metres with them, the Continental decimal comma, feet and inches. Room outlines are snapped edge by edge to the drawing's lines, and wall thickness is measured between neighbouring rooms.

Evaluation

Scored the way the work is judged.

bimp is measured on the challenge's 127,044 questions: counts must be exact, areas, lengths and volumes within 2 %. Results are reported per question type and per source, alongside citation accuracy and how often bimp correctly says "not found".

Results will be published here once the evaluation runs on the full set. We will not publish accuracy figures we have not measured.
